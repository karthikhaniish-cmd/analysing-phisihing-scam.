Step-by-step instructions for operating the scanner, interpreting threat outputs, and running PhishGuard AI locally in Windows VS Code.

Operating the Email Scanner

Either the Email Subject or the Email Body Content is required. Providing the Sender Address and any embedded Hyperlinks improves detection accuracy by allowing domain mismatch and typosquatting inspection.

  • High Risk: Classifier predicts Phishing with confidence ≥ 70% OR one or more severe heuristic indicators (credential solicitation, domain typosquatting).
  • Medium Risk: Borderline probability OR legitimate model prediction coupled with 2+ suspicious warning indicators.
  • Low Risk: Classifier predicts Legitimate with few or zero suspicious indicators.

Windows / VS Code Local Run Guide

Prerequisites: Python 3.10+ installed from python.org with "Add Python to PATH" checked.

// 1. Open Terminal in VS Code in phishguard_ai folder:
python -m venv venv
// 2. Activate virtual environment (Windows):
venv\Scripts\activate
// 3. Upgrade pip and install dependencies:
python -m pip install --upgrade pip
pip install -r requirements.txt
// 4. Train the ML model pipeline:
python train_model.py
// 5. Launch the Flask web server:
python app.py
// 6. Open in your browser: http://127.0.0.1:5000
Run Automated Unit Tests:
python -m pytest -q or python tests/test_app.py

Troubleshooting Common Issues

Missing Model File Error

If you see "Machine learning model is missing", run the training command:

python train_model.py

This generates models/phishing_model.joblib and evaluates metrics.

Port 5000 In Use

On some systems (e.g. macOS AirPlay or active Flask instances), port 5000 may be busy.

Modify the last line of app.py to use port 5001 or 8080:
app.run(port=5001)

PowerShell Script Execution

If PowerShell blocks activate.ps1 due to Execution Policy:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Alternatively, use standard Command Prompt (cmd.exe) and run venv\Scripts\activate.bat.
